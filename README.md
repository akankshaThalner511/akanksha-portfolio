# Akanksha Portfolio 2026

React + Vite portfolio project for Akanksha Thalner.

## Important Updates

- `PortfolioHero` and `AboutSection` files were kept unchanged.
- Updated professional experience, internship, projects, live projects, skills, education, training, achievements, and contact sections from the old HTML profile.
- Added contact section at the end with email, phone, LinkedIn, GitHub, location, resume download, and mailto-based contact form.
- Node 18 compatible Vite setup is used.

## Run Project

```bash
npm install
npm start
```

Open:

```text
http://localhost:5173/
```

## Build

```bash
npm run build
```
